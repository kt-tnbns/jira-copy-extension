Install in five soft steps

About thirty seconds, no build tools, nothing to sign up for.

1

Download & unzip

Grab the .zip from GitHub (or clone the repo) and unzip it somewhere permanent — the browser loads the extension from this folder, so don't delete it.

2

Open the extensions page

In Chrome (or any Chromium browser), go to chrome://extensions — type it in the address bar and press Enter.

3

Enable developer mode

Flip the Developer mode switch in the top-right corner of the page.

4

Load unpacked

Click Load unpacked and select the unzipped folder — the one containing manifest.json.

5

Pin the button

Click the puzzle-piece icon in the toolbar and pin the extension — look for — so it's always one click away.

Then, every day

Card on screen → one click → paste into Claude.

1

Open a card

Any issue page (/browse/PROJ-123) or a board with a card selected. You must be logged in to Jira in that tab.

2

Click the button

Hit the pinned toolbar button and watch for the confirmation:

✓ Copied PROJ-123
3

Paste into Claude

The clipboard now holds the full card as Markdown. Paste it into the chat and describe what you want done.

If something squeaks

The usual fixes, in order of likelihood.

Nothing happens when I click the button

The button only acts on *.atlassian.net tabs. Make sure the active tab is your Jira site and the page URL contains an issue key (/browse/PROJ-123 or ?selectedIssue=PROJ-123).

Red toast: “Jira API error 401”

Your Jira session expired in that tab. Reload the page, log in again, then click the button once more.

Red toast: “No Jira card found in this URL”

You're on a board or backlog view without a card selected. Click a card so it opens (the URL gains selectedIssue=), then retry.

Attachment URLs don't open for Claude

Attachment links require your Jira login, so Claude can't fetch them itself. Drag the actual image or file into the chat alongside the pasted text when it matters.

The extension disappeared after a browser update

Unpacked extensions stay installed, but if it's gone, repeat the install steps — the folder on disk is the source of truth, nothing else to rebuild.
